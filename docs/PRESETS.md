# Стили (пресеты) — как добавлять

Пользователю пресеты называются **Стили**. Это наброски для Claude-режиссёра: он выбирает стиль под момент ролика и подставляет параметры. Код — `apps/web/src/presets/` (позже переедет в `packages/presets`, чтобы рендер-воркер брал те же файлы).

## Порядок: образец → стиль

Владелец присылает ролик и говорит, что нравится («переход на 0:12», «субтитры как с 0:03»).

1. **Кадры вокруг момента.** Claude видит кадры, не видео:
   ```sh
   ffmpeg -ss 00:00:11.5 -t 2 -i ref.mp4 -vf "fps=12,scale=360:-1" frames/%03d.png
   ```
   Плавное быстрое движение — `fps=24` на 1 сек. Момент не указан — сначала `fps=1` по всему ролику, найти эффект, потом крупно.
2. **Разобрать эффект:** что движется, за сколько кадров, какие кривые (резкий вход / пружина / плавный), как сочетается с речью (на слово, на склейку, на начало).
3. **Найти похожий стиль** в реестре (`registry.ts`).
   - Похожий есть → вариация (новый id, своё имя), а не правка старого.
   - Нет → новый стиль в подходящей категории.
   - Не подходит ни одна категория → новая (см. ниже).
4. **Написать стиль** (правила ниже).
5. **Проверить:** `pnpm --filter @lumenkit/web typecheck`, затем кадры стиля на `/presets` рядом с кадрами образца. Расхождение в тайминге или кривой — поправить и снять снова.

Короткие нарезки образцов (3–5 сек, до 5 МБ) — в `design/refs/effects/`, имя по эффекту: `whip-transition.mp4`. Полные ролики в git не кладём.

## Виды стилей (`kind`)

| kind | Что делает | Примеры |
|---|---|---|
| `overlay` | слой поверх ролика | субтитры, плашки, акценты, переходы |
| `wrapper` | трансформация кадра ролика (`transform` по кадру) | зумы, тряска, наезд |
| `scene` | перестраивает кадр целиком, ролик пользователя — внутри | хук-сцена, телефон в 3D, разделённый экран |

## Категории

`captions` Субтитры · `plates` Плашки · `zooms` Зумы · `transitions` Переходы · `hooks` Хуки · `scenes` Сцены.

Новая категория — две строки: id в `PresetCategory` (`types.ts`) и подпись в `labels` (`registry.ts`); вкладка в «Стилях» появится сама. Если стиль должен ставиться на свою дорожку — ещё `trackCategories` в `components/editor/inspector.tsx`. Категорию заводим, когда в ней будет хотя бы 3 стиля; одиночку — в ближайшую.

## Обязательно в каждом новом стиле

- `name` — по-русски, коротко, как называл бы креатор («Хлыст», «Неоновое слово»); по имени его находит токен `{Хлыст}`.
- `description` — что видно на экране, одна фраза.
- `useWhen` — **когда ставить**, одна фраза для режиссёра: «на склейку после паузы», «первые 2 сек», «на цифру в речи». Без этого Claude выбирает стиль только по названию.
- `dimension` — `2d` / `2.5d` / `3d` (см. ниже).
- `schema` — zod через хелперы `fields.ts` (иначе теряется мета для формы). Всё, что пользователь может захотеть поменять (текст, цвет, сила, длительность), — параметр, а не константа.
- `demoBg`, `posterFrame` (самый выразительный кадр для обложки), `previewFrames`, `defaultSeconds`.

## Правила кода

- Анимация **только по кадрам**: `useCurrentFrame`, `interpolate`, `spring`. Никаких `motion/react`, CSS-transition, `setTimeout`, `Math.random()` без сида (рендер должен давать одинаковые кадры).
- Цвета и шрифт — из параметров/бренд-кита, не хардкод.
- Безопасные зоны 9:16: верх ~10% и низ ~20% заняты интерфейсом соцсетей; субтитры не выше низа лица.
- Звуки в стиль не встраиваем — их подбирает режиссёр.
- Коммерческие шаблоны (Motion VFX и т.п.) и OpenMontage — только как образец вида и движения. Их файлы, модели, текстуры, звуки и код не копируем.

## Объём: 2D / 2.5D / 3D

| | Чем | Стоимость рендера |
|---|---|---|
| `2d` | обычные трансформации и слои | дешёво |
| `2.5d` | CSS `perspective` / `rotateX/Y` / параллакс слоёв | почти как 2D |
| `3d` | Three.js через `@remotion/three` (`ThreeCanvas`), анимация тоже по кадрам | в разы дороже: на сервере без видеокарты WebGL считает процессор |

- Сначала пробовать 2.5D — большинство «3D» в шортсах это оно.
- 3D — короткими кусками (хук, концовка, акцент 1–3 сек), не на весь ролик. Режиссёр это учитывает по `dimension`.
- Фотореализм и сложные симуляции — не стилями, а генерацией (Seedance) вставкой.
- `@remotion/three` и `three` ещё не установлены — ставить при первом 3D-стиле той же версии, что `remotion`. Первый 3D-стиль — с замером времени рендера.

## Предпросмотр

Карточка в библиотеке играет по наведению (на телефоне — в центре экрана); клик на главной и в редакторе открывает крупный просмотр с паузой и перемоткой (`components/preset-preview.tsx`), «+» добавляет в промпт. Отдельно ничего делать не нужно — превью строится из той же композиции (`PresetPreviewComp`).
