# Montage — план проекта

Бренд: **Lumen Kit** (решение от 2026-10-14; «Montage» — кодовое имя репозитория). Сначала студия для креаторов, позже — AI-агенты для соцсетей, аналитика.
Состояние прототипа UI и контракты для бэкенда: `docs/PROTOTYPE.md`.

Браузерный сервис автомонтажа коротких роликов (до 60 сек) и генерации отдельных моушен-вставок, которые пользователь скачивает и вставляет в свой монтаж. Claude выступает режиссёром: выбирает пресеты и параметры, а не рисует всё с нуля.

Длинные ролики — вне скоупа (решение от 2026-10-12).

## Продукт

- **Автомонтаж шортсов:** загрузка видео → транскрипция → Claude строит JSON-таймлайн (пресеты + параметры) → мгновенный предпросмотр в Remotion Player → правки чатом/руками → рендер.
- **Режим «Вставка»:** промпт → клип → скачать. Экспорт: MP4 (H.264), с альфа-каналом (ProRes 4444 .mov / WebM), хромакей.
- **Пресеты:** библиотека (50+ вариаций на категорию: плашки, зумы, переходы, субтитры…). Пресет = React-компонент Remotion + zod-схема параметров + метаданные + бренд-кит пользователя. Форма настроек генерируется из zod-схемы.
- **Наброски + свободная генерация (решение от 2026-10-14):** шаблоны сцен — не жёсткая форма, а набросок. Пользователь пишет свободный промпт; сервис подбирает похожие наброски (по смыслу фразы и стилю), Claude получает их код как пример и адаптирует или смешивает их, а если подходящих нет — пишет сцену с нуля. Все сцены опираются на единую дизайн-систему (токены, правила движения). Перед выдачей — автопроверка (lint/check/снимки) и самоисправление. Наброски экономят токены и попытки; удачные свободные сцены пополняют библиотеку. Проба: `videos/claude-motion/` (HyperFrames, 8 сцен под озвучку).
- **Редактор:** prompt-first, не полноценный NLE. Чат/поле промпта + Player + таймлайн из блоков + замена пресетов + монтаж через текст (удалил слово → вырезалось). Решение от 2026-10-16: редактор остаётся (он работает в браузере и серверу ничего не стоит, а ручные правки бесплатны в отличие от правок через Claude), только полный таймлайн, без «простого» режима.
- **Промпт — главный интерфейс (решение от 2026-10-16):** стили, плашки и генерации пишутся токенами прямо в тексте — `{Удар}`, `{Telegram: @канал}`, `{nano-banana: промпт}`; порядок токенов = порядок в ролике. Пресеты пользователю называются «Стили». Подробно — `docs/PROTOTYPE.md`.
- **AI-режиссёр Авто/Вручную:** по умолчанию Авто — Claude сам выбирает модели (реестр `lib/models.ts`: Nano Banana, GPT Image 2, Seedance 2.5; новая модель = одна запись), пишет промпты и сшивает результат в монтаж в пределах лимита кредитов. Вложения как в Claude (фото/файлы → референсы или вставка как есть).
- **Генеративные вставки:** Nano Banana и GPT Image 2 (картинки, Claude итерирует с проверкой, лимит 2–3 попытки) + удаление фона (BiRefNet/rembg) + библиотека ассетов; Seedance (видео, image-to-video). Результат ложится на отдельную дорожку «AI-вставки».
- **Биллинг:** кредиты; разная цена у генерации, правки, AI-сцены, Seedance.

## Стек

- Монорепо: pnpm + Turborepo, TypeScript.
- Веб: Next.js (App Router), Tailwind v4 (токены), shadcn/ui (кастомизированный), Motion (`motion/react`) — **только для UI сайта**.
- Auth: Better Auth (email, Google, Telegram).
- БД: PostgreSQL + Drizzle. Очереди: Redis + BullMQ. Прогресс: SSE.
- Хранилище: S3-совместимое (MinIO локально).
- Видео: Remotion (пресеты, Player, рендер), HyperFrames (свободные AI-сцены на HTML/GSAP), ffmpeg.
- AI: Claude API — Sonnet 5.5 (план монтажа), Opus 5.5 (сложные AI-сцены), Haiku 5.5 (теги, модерация). Whisper для транскрипции.
- Генеративные провайдеры через адаптеры: `ImageProvider` (Nano Banana, GPT Image 2), `VideoProvider` (Seedance).
- Claude только через API: подписку Pro/Max нельзя использовать как движок сервиса.
- Шлюз моделей — **OpenRouter** (решение от 2026-10-17): один ключ на Claude, транскрипцию (STT с таймингом слов), картинки и видео (Seedance 2.5). Адаптеры `ImageProvider`/`VideoProvider`/STT остаются — OpenRouter лишь их первая реализация, прямого провайдера можно подключить без правок вызывающего кода.
- Инфра: Docker Compose локально и на Ubuntu, Caddy, Sentry. Воркеры масштабируются горизонтально: media / ai / render / image / gen.

## Важные правила

- Внутри Remotion-композиций анимации только по кадрам (`useCurrentFrame`, `interpolate`, `spring`). Motion/Framer Motion там не использовать. В HyperFrames — GSAP-таймлайны.
- Логировать `usage` каждого запроса к Claude и генеративным API в БД с первого дня.

## Себестоимость (оценки, уточнить на прототипе)

| Сценарий | ≈ стоимость |
|---|---|
| Шортс на пресетах (Sonnet + рендер) | $0.20–0.35 |
| Шортс + 3 картинки Nano Banana | $0.35–0.75 |
| Вставка 5–10 сек на пресетах | $0.05–0.15 |
| Вставка + картинка + Seedance | $0.5–1.5 |
| AI-сцена с нуля (Opus) | +$0.6–1.2 |
| Шортс 30 сек: Claude Авто + HyperFrames по наброскам (Sonnet), ролик + фото, без генеративных API | $0.3–0.6 |
| То же, все сцены с нуля (Opus) | $0.8–1.5 |

Цены Claude (за 1M токенов, вход/выход): Sonnet 5.5 $2/$10, Opus 5.5 $4/$20, Haiku 5.5 $0.10/$0.50; чтение кэша $0.20.
Основная статья расходов — токены на перегенерации и правки и генеративные API, рендер стоит копейки (свой сервер ≈ $0.002–0.005 за шортс, Remotion Lambda ≈ $0.01–0.03). Цена для пользователя — наценка ×3–5 к себестоимости.

## Рендер и сервер (решение от 2026-10-16)

- Старт: **один сервер** — 8 выделенных ядер, 32 ГБ, NVMe ~160 ГБ (≈40–80 €/мес): сайт, API, Postgres, Redis, все воркеры. Рендеру — лимит 5–6 ядер в Docker, 1–2 рендера одновременно, остальное в очереди BullMQ. Whisper — по API, файлы — в S3 (R2), бэкап Postgres ежедневно наружу.
- Рост: второй сервер подключается как ещё один render-воркер к той же очереди, без изменений кода. На пики — Remotion Lambda.
- Экономия рендера: вставки — рендер в браузере пользователя (`@remotion/web-renderer`, экспериментально — проверить зрелость); шортсы — гибрид (Remotion рисует только слой графики с альфой, ffmpeg делает склейки, зумы, наложение и звук); кэш по кускам 5–10 сек при повторных экспортах; черновой экспорт 720p.
- Первым делом на каркасе — бенчмарк Remotion на `ShortComposition` (секунды рендера на 8/16 ядрах).
