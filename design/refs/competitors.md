# Конкуренты: UI/UX для креаторов (исследование 2026-10-12)

> Кабинетный обзор: без входа в сервисы. **[проверить]** — визуальные детали, которые нужно подтвердить скриншотами. Остальное — по справке вендоров и отзывам (источники внизу).

## Аудитория Montage

- **Креаторы шортсов и блогеры (talking head)** — Reels/TikTok/Shorts, часто с телефона, ждут «загрузил → через минуту готово».
- **SMM-менеджеры и малые агентства** — поток роликов, бренд-кит, предсказуемая цена.
- **Видеомонтажёры** — режим «Вставка»: моушен-плашки с альфой для Premiere/DaVinci/CapCut.
- Рынок — русскоязычный в первую очередь: Telegram-вход, оплата РФ-картами/СБП, русские названия стилей. Устройства: телефоны и ноутбуки среднего уровня → лёгкий фронт обязателен.

## По инструментам

### Submagic (submagic.co) — главный конкурент по субтитрам
- Вход: «Generate Captions» → drag&drop → язык/спикеры → ~40 сек обработки. Шаблон выбирается уже в редакторе.
- Редактор: превью 9:16 по центру; разделы Trim (тишина, дубли), Style (шаблоны), Edit Captions (слова, highlight, эмодзи), Hook Title, Music, B-roll (слайдер частоты), Transitions, Zooms, Export (до 4K, 30/60 fps).
- Сильное: шаблоны «в стиле креаторов» (Hormozi и т.п.). Только веб, без приложения.
- Жалобы: рассинхрон, глюки шрифтов, нет возвратов.

### Opus Clip (opus.pro) — нарезка длинного
- Ссылка/файл → настройки (формат, длина, промпт) → карточки клипов с **Virality Score 0–100**.
- Редактор по тексту + таймлайн, reframe, AI B-roll, экспорт XML в Premiere/DaVinci.
- Кредиты = минуты **исходника**. Жалобы: править ошибки AI дольше, чем резать самому; субтитры поверх вшитых; списания после отмены.

### Captions / Mirage (captions.ai)
- Mobile-first. **AI Edit**: выбрал стиль → склейки, темп, субтитры, музыка, B-roll → правки чатом. Пикер стилей лентой карточек **[проверить]**.
- Жалобы: перегруженный UI, базовые настройки субтитров теряются; лаги, рассинхрон после правок; непредсказуемый расход кредитов.

### CapCut (web/desktop)
- Классический NLE: иконочная колонка слева + выезжающая панель ассетов, плеер, инспектор справа, многодорожечный таймлайн. Тёмный, бирюзовый акцент **[проверить]**.
- Шаблоны с автоплеем превью.
- **Главная боль — пейволл на экспорте**: 26% негатива «только в Pro», Pro-эффекты не помечены в меню. В РФ не проходят карты.

### Descript
- Видео как документ. **Underlord** — AI-агент в правом сайдбаре: чат, выбор модели, @-упоминания сцен/таймкодов, предпрослушка до вставки, история чата (с мая 2026).
- Кредиты отдельно за агента и каждый инструмент — пользователи путаются.

### VEED — сайдбар инструментов + таймлайн. Жалобы G2: тормоза в браузере (280), слабый AI (215).

### Higgsfield (higgsfield.ai)
- Три входа: Create Video / Cinema Studio / Edit Video. Витрина эффектов плиткой с зацикленными превью, тёмный UI, кислотно-лаймовый акцент **[проверить]**. Бейджи TOP/NEW у моделей.
- Жалобы: **цена в кредитах не видна до генерации** (разница моделей до 3×), плохо на мобиле/iPad, не запоминаются дефолты (9:16, модель).

### Kling / Krea / Runway — генеративный UI
- Поле промпта + референс-картинка, компактные параметры (формат, длительность, модель, кол-во), лента истории с состояниями «в очереди → генерируется → готово», действия повторить/вариация/скачать **[проверить]**.
- Krea: единая навигация, прозрачный выбор модели, клик по картинке → её промпт → перегенерация.

### Hedra — промпт как вход, галереи шаблонов, Elements-конструктор против «пустого листа».
### Vizard / Klap / Reap — правка по тексту; Klap — минимум контроля; Reap — agent-first (API, CLI, MCP).

## Что аудитория уже ожидает (берём)
1. Первая загрузка без настроек: drag&drop → автоязык → результат ~минута. Бренд-кит — после первого «вау».
2. Вертикальный плеер 9:16 — центр экрана.
3. Пресеты плиткой с живым превью, применение в один клик.
4. Правка по тексту + «убрать паузы» / «убрать дубли».
5. Правка субтитров в тексте, highlight ключевых слов, эмодзи.
6. AI-ассистент в правой панели с историей и @-упоминаниями.
7. Тёмная тема, яркий акцент, бейджи NEW/TOP.
8. Лента генераций для «Вставки» со статусами.
9. Пресеты экспорта: 1080p, 30/60 fps, прозрачность.

| Боль | Где |

## Наши отличия (в прототип)
1. **Цена на кнопке**: «Сгенерировать · 3 кр.», баланс всегда в шапке, предупреждение до начала работы.
2. **Без ловушек на экспорте**: платные пресеты помечены в плитке; предпросмотр всегда бесплатный.
3. **Правки чатом с диффом**: «+зум 00:12, заменена плашка» → принять / откатить; история версий.
4. **Ручная правка рядом**: клик по блоку → форма пресета (из zod) + «Заменить на…» с похожими.
5. **Цена за ролик/правку, а не за минуты исходника** (у нас ≤60 сек).
6. **Мгновенный предпросмотр** в Remotion Player — без спиннеров при смене стиля.
7. **Лёгкость**: превью пресетов — лёгкие webm/постер, играют только в зоне видимости; на мобиле режим «чат + плеер + список блоков».
8. Предупреждение о вшитых субтитрах в исходнике.
9. Запоминание дефолтов: 9:16, бренд-кит, любимые пресеты, формат экспорта вставок.
10. Telegram-вход, полностью русский UI.
11. «Вставка» — лента генераций, но с параметрами пресета; бейдж «с альфой».
12. Отмена подписки и возвраты в 1–2 клика.
