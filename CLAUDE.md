# Lumen Kit (кодовое имя Montage)

Браузерный SaaS: автомонтаж шортсов (≤60 сек) и моушен-вставки на Remotion/HyperFrames, Claude — режиссёр поверх библиотеки пресетов-набросков.

Полный план, стек, себестоимость и решения: @docs/PLAN.md
Прототип UI (утверждён), язык промпта, контракты для бэкенда, что заглушено: @docs/PROTOTYPE.md

**Сейчас:** шаг 3 плана — каркас монорепо и бэкенд. UI — `apps/web` (бывший `prototype/`, эталон экранов), не перерисовываем. Общий код для браузера и бэкенда (парсер токенов, реестр моделей, типы таймлайна) — `packages/core`. Локальная инфраструктура — `docker compose up -d` (Postgres, Redis, MinIO), веб — `pnpm dev`.

## Правила

- Общение с пользователем на русском.
- Внутри Remotion-композиций анимации только по кадрам (`useCurrentFrame`/`interpolate`/`spring`); Motion (`motion/react`) — только для UI сайта. Импорт всегда из `motion/react`, даже если скил (`motion-framer`) показывает `framer-motion`.
- UI-скилы: `ui-ux-pro-max` (дизайн-система, палитры, UX-правила), `motion-framer` + `motion-*` (анимации UI), `frontend-design`. Пресеты — Remotion-скилы. AI-сцены — скилы `hyperframes*`.
- Дизайн: тёмная тема по умолчанию (светлая — по кнопке, токены `:root[data-theme="light"]`), токены Tailwind, никаких хардкод-цветов. Перед сдачей экрана — скриншот и сверка с прототипом и референсами из `design/refs/` (правила — `design/refs/ui-principles.md`).
- Промпт — главный интерфейс: стили, плашки и генерации — токены в тексте (`{Удар}`, `{Telegram: @канал}`, `{модель: промпт}`). Новые фичи режиссёра читают распарсенные токены, а не отдельные формы. Пресеты пользователю называются «Стили».
- Генеративные модели — только из реестра (`lib/models.ts`) и только через адаптеры провайдеров (`ImageProvider` / `VideoProvider`). AI-режиссёр по умолчанию в режиме Авто с лимитом кредитов.
- Claude в продукте — только через API (подписка Pro/Max как движок сервиса запрещена). Логировать `usage` каждого запроса к Claude и генеративным API с первого дня.
- Ролики `AQ*.mp4` в корне — эталон того, что должен выдавать наш рендер, не UI-референсы.
- Скоуп: только ролики до 60 сек и вставки; длинные ролики не делаем.
- OpenMontage (`C:\OpenMontage`, AGPL) — только как референс, код в проект не копировать.
